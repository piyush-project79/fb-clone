# FB Clone

A full-featured **Facebook-inspired social media website clone** that I built while learning and practicing Git and GitHub during our Git tutorial.

The project started as a basic Facebook UI clone and was extended with additional pages, components, and interactive features to make it feel more like a complete social media platform.

### Features

* 🏠 Home/news feed
* 👤 User profile page
* 📝 Create and share posts
* ❤️ Like and interact with posts
* 💬 Comment section
* 👥 Friends/user section
* 🔔 Notifications interface
* 💬 Messaging/chat interface
* 🔍 Search functionality
* 📱 Responsive design for different screen sizes
* 🎨 Facebook-inspired modern UI
* 🧩 Reusable components and organized project structure

### Purpose

This project helped me practice:

* Git and GitHub workflow
* Version control and commits
* Branching and merging
* Front-end development
* Responsive web design
* Component-based development
* Building and organizing a larger web project
